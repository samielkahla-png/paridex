À propos de Paridex

⚡ Architecture Dual API

Paridex utilise deux API professionnelles pour 100% de données réelles :

1. The Odds API (500 req/mois) → cotes 1X2 en temps réel auprès de 40+ bookmakers (Unibet, Betclic, Winamax...)

2. API-Football (75 000 req/jour) → forme des équipes, stats sur la saison, BTTS, Over/Under, predictions agrégées multi-algorithmes

Les deux API sont croisées pour donner les meilleurs combinés.

🧠 Predictions API-Football

L'endpoint /predictions d'API-Football utilise 6 algorithmes différents calculant :

• Le winner probable + commentaire d'analyse
• Pourcentages de victoire H/N/A
• Comparaisons de forme, attaque, défense, H2H
• Conseil agrégé (advice)

C'est l'équivalent de "scanner 10 sites d'experts" — sauf que c'est des algorithmes réels qui s'appuient sur des centaines de matchs historiques.

📊 Pondération du risque

Score composite /100 calculé sur 3 critères réels :

• 50% Fiabilité = probabilité implicite × bonus patterns détectés (W7, BTTS, etc.)
• 25% Score Experts = % winner depuis predictions API-Football
• 25% Rendement = gain potentiel

Verdicts : 🔒 Très sûr (P ≥ 70%) · ✅ Sûr (≥ 55%) · ⚡ Modéré (≥ 40%) · ⚠️ Risqué (< 40%)

📋 Stats sur 10 derniers matchs

Pour chaque match enrichi, l'app affiche :

• Forme 5 derniers (W-W-D-L-W) avec dots colorés
• Bilan saison : XV-XN-XD
• BTTS : X/10 (les 2 équipes ont marqué)
• +2.5 buts : X/10
• Clean sheets : X/10
• Patterns détectés : Série dom., +1.5 buts, etc.
